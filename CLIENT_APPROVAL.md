# Seven Films - Website Direction Approval

## Purpose
This document is for approval of the website's visual and structural direction before final development and deployment. It is not a final content sign-off.

## Direction proposed
- Premium cinematic production-studio look using Seven Films' red / black identity.
- Strong editorial typography, large-format imagery, motion-led transitions and a restrained production aesthetic.
- A provisional SF brand lockup is used in the prototype and can be replaced by the final logo file without changing the layout.
- Portfolio cards use one consistent three-column desktop system so project presentation stays clean and intentional.

## Website flow covered from the supplied company profile
1. Hero / positioning - local and global production partner.
2. About / studio profile - Karachi base, international production network and script-to-screen positioning.
3. The Way We Work - collaboration, storytelling and brand alignment.
4. Our Strength - local + global production teams and scalable crew model.
5. Selected Work - profile projects with supplied YouTube / Vimeo links.
6. Global Production Network - Pakistan, UAE, Turkey, Thailand, Sri Lanka, Singapore, Poland and India.
7. Brands We Work With.
8. Production Partners.
9. Contact - website, email, phone and Karachi office address.

## Deliberately held for phase two
- Services: component and data structure are prepared, but the public section remains hidden until the client finalises service copy.
- Upcoming Ventures: section is prepared as a future module and remains hidden for this approval round.

## Items to confirm before final launch
- Final Seven Films logo / identity asset.
- Final project order, titles and credits.
- Final brand and production-partner logo files.
- Social media handles / URLs.
- Services copy and Upcoming Ventures content when ready.
- Domain, cPanel document root, SSL and hosting environment.

## Technical direction
React + Vite, component-based architecture, CSS custom properties for the design system, reusable portfolio/data components, responsive layouts, Framer Motion interactions and a static production build suitable for normal cPanel deployment.
